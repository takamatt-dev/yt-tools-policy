Privacy Policy

Last updated: November 27, 2026

This policy describes a small personal tool that its owner uses to manage the owner's own YouTube channels. The tool is not offered to the public, and only the owner signs in to it.

What the tool accesses

With the owner's permission through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to upload and schedule the owner's own videos, set thumbnails, manage live streams, post and manage the owner's own comments and replies, and read the owner's channel statistics (views, watch time, impressions).

How the data is used and stored

The data is used only to run and improve the owner's own channels. Sign-in tokens are stored on the owner's own computer. Statistics may be kept in the owner's private notes. Nothing is sold or used for advertising. Data is not shared with others except service providers the owner uses to store and analyze the owner's own channel data.

Viewers

The tool does not build profiles of viewers. Public comments, with their public author names, may be read to reply to them, under YouTube's own terms.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube's privacy practices are described in the Google Privacy Policy, and use of YouTube is subject to the YouTube Terms of Service.

Removing access

Access can be removed at any time from the Google Account permissions page: myaccount.google.com/permissions.

Contact

Questions can be sent by opening an issue in this site's GitHub repository.
